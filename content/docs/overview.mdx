# Introduction to TokenGecko

TokenGecko is a developer workbench engineered to inspect, tokenize, benchmark, and optimize LLM prompt payloads across all major model providers in real time.

Whether you are building complex multi-turn agent pipelines, optimizing RAG context windows, or auditing token consumption costs, TokenGecko provides granular insights before you execute requests against production APIs.

## Core Capabilities

- **Real-Time Tokenization**: Exact Byte-Pair Encoding (BPE) parsing using Tiktoken and custom tokenizers.
- **Provider Multi-Benchmarking**: Compare token counts, context window fill %, and estimated input/output costs side-by-side.
- **BYOK (Bring Your Own Key)**: Secure client-side API key vault with zero server-side storage of sensitive credentials.
- **Prompt Payload Analysis**: Inspect structured prompt components (system instructions, user turns, function schemas).

## Architecture Overview

TokenGecko runs natively in the browser with minimal backend overhead:

```typescript
import { TokenGeckoInspector } from '@tokengecko/core';

const inspector = new TokenGeckoInspector({
  models: ['gpt-4o', 'claude-3-5-sonnet', 'gemini-1.5-pro'],
});

const analysis = await inspector.analyze({
  systemPrompt: 'You are an expert software engineer...',
  userPrompt: 'Refactor this database query for optimal index usage.',
});

console.log(analysis.tokenCounts);
```
