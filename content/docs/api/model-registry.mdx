# Model Registry API

The **Model Registry** module provides programmatic access to TokenGecko's canonical registry of LLM metadata, token limits, and pricing structures.

## Fetching Model Metadata

```typescript
import { ModelRegistry } from '@tokengecko/core';

// Get spec for a specific model
const modelSpec = ModelRegistry.getModel('claude-3-5-sonnet');
console.log(modelSpec.contextLimit); // 200000

// List all models by provider
const openAiModels = ModelRegistry.getModelsByProvider('openai');

// Filter models by context capacity minimum
const largeContextModels = ModelRegistry.filter({
  minContextLimit: 128000,
});
```
