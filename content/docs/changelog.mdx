# Changelog

All notable changes to the TokenGecko web app and core inspection engine are documented here.

## [v1.1.0] - 2026-08-05

### Added
- **Dedicated Documentation Surface (`/docs`)**: Added sidebar navigation, command-palette search (`⌘K`), keyboard shortcuts, and MDX-based guide pages.
- **DeepSeek V3 & R1 Model Registrations**: Added pricing and context metadata for DeepSeek V3 and reasoning models.
- **Enhanced BYOK Key Storage**: Client-side AES-GCM encryption for API keys in local storage.

### Improved
- **Real-Time BPE Tokenizer**: Instant client-side Tiktoken parsing performance boost for large payloads (>50k tokens).
- **Responsive Layout**: Dark theme visual polish matching `--bg-app` design tokens.

- Initial public release of TokenGecko Prompt Inspector.
