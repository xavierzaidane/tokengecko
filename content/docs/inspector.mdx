# The Inspector Workspace

The **Inspector** is TokenGecko's primary developer workspace. It enables developers to inspect, tokenize, and optimize complex prompt payloads across multiple LLMs simultaneously.

## Workspace Layout Overview

The Inspector interface is divided into three primary zones:

1. **Input & Payload Editor**: Supports markdown, raw text, and structured JSON payloads.
2. **Model Leaderboard & Comparison**: Displays side-by-side tokenization stats across selected models.
3. **Context Utilization & Cost Gauges**: Visual charts detailing context window capacity and financial metrics.

## Key Features

### 1. Multi-Provider Tokenization

Different model providers use distinct tokenization algorithms:
- **OpenAI (`o200k_base` / `cl100k_base`)**: Tiktoken-based BPE encoding.
- **Anthropic**: Claude token estimators accounting for special system framing tokens.
- **Gemini**: SentencePiece-derived tokenization with multi-modal payload support.

TokenGecko highlights how the same prompt payload converts into different token lengths across providers.

### 2. Context Capacity Radial Gauges

- `gpt-4o`: **128,000 tokens**
